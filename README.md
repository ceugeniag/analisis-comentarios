## Descripción del dataset
Archivo CSV con comentarios de usuarios. Se analiza frecuencia de palabras
y se clasifican comentarios como positivos o negativos mediante palabras clave.

## Instrucciones para ejecutar
1. Abrir el notebook en Google Colab
2. Ejecutar las celdas en orden
3. Los resultados se guardan en /resultados
